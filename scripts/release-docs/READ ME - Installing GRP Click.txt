GRP CLICK  -  version {{VER}}  ({{DATE}})
==============================================================

GRP Click lets Bitfocus Companion (Stream Deck) change slides in
PowerPoint or Keynote on the presentation machines.

  GRP CLICK - the app, on each presentation machine. Opens a window
              that shows it's connected, the slide, and its IP address.
  MODULE    - goes on the Companion machine (see "Companion module").


Which file do I need?
---------------------
  Mac: Apple menu > About This Mac.
    "Chip: Apple M1/M2/M3/M4..."  ->  Mac - Apple Silicon
    "Processor: Intel..."         ->  Mac - Intel
  Windows laptop                   ->  Windows

Copy the file to the machine first (don't run it from the NAS).


MAC
---
1. Double-click the .dmg and drag GRP Click into Applications.
2. Open it from Applications. The first time, macOS will say it can't
   check the app. Click Done (not Move to Bin).
3. Open System Settings > Privacy & Security, scroll down, and click
   "Open Anyway" next to GRP Click. Enter the Mac's password.
   You only do this once per machine.
4. With GRP Click open, open the deck. macOS asks
   "GRP Click wants to control Keynote / PowerPoint" - click OK.
   Do this before the show.
5. Eject the "GRP Click" disk on the desktop.

Updating: just do steps 1-2 again over the top. Settings are kept.
Quit GRP Click first - never update during a show.


WINDOWS  (NOT TESTED YET - use a Mac for shows until it has been)
-------
1. Double-click GRP-Click-Setup-{{VER}}.exe.
2. If a blue "Windows protected your PC" box appears:
   click "More info", then "Run anyway".
3. Follow the installer. It puts a GRP Click icon on the desktop.
4. When Windows Firewall asks, allow it (tick Public too if the show
   network has no internet).

Updating: run the new Setup over the top. Settings are kept.


THE WINDOW
----------
  Green  "Companion connected"   - it's working
  Amber  "Waiting for Companion" - put the IP address shown into the
                                   GRP Click connection in Companion
  Red    "Not listening"         - read the message (usually another
                                   copy is already running)
  Presentation   the app and slide, e.g. Keynote 2 / 12
  Last commands  every press, with a tick or the reason it failed

Close the window and GRP Click keeps running in the menu bar (Mac) /
system tray (Windows). It opens by itself when the computer starts.


ON THE NIGHT
------------
- Open the deck first. GRP Click never opens PowerPoint or Keynote.
- Start show / End show / Next / Back / First / Last work in both.
- Go to slide works in Keynote and PowerPoint for Windows,
  not PowerPoint for Mac.
- Mac with both PowerPoint and Keynote open: it controls the one
  with a slideshow running, else the one with a deck open.
- Keynote: pressing Next brings the show to the front if something
  else was clicked on the presentation Mac.
- Buttons go RED when the machine can't be reached, AMBER when the
  last press didn't work (e.g. no slideshow running).

No password: use it on the show network only, never guest Wi-Fi.
