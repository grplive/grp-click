GRP Click 1.1.0 · Companion module 1.1.1

**GRP Click is now an app**, like GRP Stage Timer and GRP Notes, instead of a hidden background receiver. It opens a window showing:
- **Companion connected** (green) or **Waiting for Companion**, and from where
- the app and slide on screen, e.g. *Keynote · 2 / 12*, with Start / Back / Next / End buttons to try it before the show
- this computer's IP addresses for Companion
- the last few commands, with ✓ or the reason one failed

Close the window and it keeps running in the menu bar / system tray, with the slide shown there. It opens when the computer starts, and tells you when an update is out. Installs are now a normal .dmg (Mac) and Setup .exe (Windows). On a Mac that had the 1.0 receiver installed, remove it: delete `/usr/local/grp-click` and `/Library/LaunchAgents/com.grp.click.receiver.plist`, then restart. While the old one is running, GRP Click shows "Not listening".

**Fixes (after testing with PowerPoint 16.115, Keynote and Companion 5.1.3)**
- **Never opens PowerPoint or Keynote.** A press with nothing open used to launch PowerPoint; now it reports "Neither PowerPoint nor Keynote is open".
- **No stray key presses.** When a command failed, the 1.0 receiver pressed an arrow key in whichever app was in front (on a show Mac that could be the timer or a browser) and still reported success. That fallback is gone.
- **Keynote Next/Back now work when another app is in front.** Keynote only takes those while it's frontmost, so GRP Click brings the show forward first.
- **Keynote First, Last and Go to slide** now work (they weren't there before). Start show always starts at the first slide.
- **PowerPoint for Mac Go to slide** never worked (PowerPoint for Mac can't do it during a show). It now says so plainly.
- **With PowerPoint and Keynote both open on a Mac**, it now controls the one with a slideshow running, then the one with a deck open, then the one in front. It used to always pick PowerPoint, even with nothing open in it.
- Start show while a show is already running does nothing, instead of restarting it.

**Windows (not tested yet)**
- A normal installer like GRP Notes; Windows Firewall asks on first launch.

**Companion module**
- **Slide position on a button**: the new Slide preset shows e.g. *Keynote 2/12* and goes green while the show runs. It follows the presenter's own clicker too. Variables `mN_slide`, `mN_slide_number`, `mN_slide_total`, `mN_app`.
- Now **GRP Live: Click** (`grplive-click`), built for Companion 4 and 5. Remove the old "GRP Click" connection and add the new one.
- Buttons turn **red** when a machine can't be reached and **amber** when the last press didn't work.
- Variables per machine: status, Mac/Windows, GRP Click version, last error.
- Presets for Machines 1 and 2, including Go to slide and a status button.

Builds aren't signed: Mac needs **Open Anyway** once (System Settings → Privacy & Security), Windows needs **More info → Run anyway**.
