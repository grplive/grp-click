GRP Click

Free slide control for PowerPoint and Keynote from Bitfocus Companion and Stream Deck. Install the receiver on each presentation machine.

Mac – Apple Silicon Mac – Intel Windows

First install: on a Mac, if it says it can’t check the installer, click Done, then System Settings → Privacy & Security → Open Anyway. On Windows, unzip, run install.bat, and if asked click More info → Run anyway. Only needed once.

Not sure which Mac? Apple menu → About This Mac: “Chip: Apple M…” is Apple Silicon; “Processor: Intel” is Intel.

Then add the GRP Click module in Companion (module file) and enter each machine’s IP address. Release notes & older versions.
